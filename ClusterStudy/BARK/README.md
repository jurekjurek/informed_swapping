# ClusterStudy

Systematic cluster study of **BARK vs SKQD** over a 5-dimensional parameter grid.

Each job runs the experiment that was originally done manually in
`../compare_bark_skqd.ipynb`:

1. Build a random Hamiltonian with controlled ground-state and Hamiltonian sparsity.
2. Pick an initial state with a target overlap with the true ground state.
3. Run SKQD for 12 different time steps and compute the energy-vs-subspace-size path.
4. Compute `N` random orderings as a baseline.
5. Run BARK with a fixed `keep_states` budget.
6. Save a comparison figure to `results/`.

## Directory layout

```
ClusterStudy/
├── run_experiment.py   # Single-job script (takes 5 CLI flags)
├── generate_jobs.py    # Writes params/param_grid.txt from the chosen grid
├── run_array.slurm     # Slurm array job that reads param_grid.txt
├── params/
│   └── param_grid.txt  # One line per job (generated by generate_jobs.py)
├── results/            # Output PNGs (one per job)
└── SlurmOut/           # Slurm stdout/stderr logs
```

## Hyperparameters

| Parameter | Values (full grid) | Description |
|-----------|-------------------|-------------|
| `n_qubits` | 6, 7, 8, 9, 10 | System size; Hilbert-space dim = 2^n |
| `gs_sparsity` | 0.05, 0.1, 0.25, 0.5, 0.75, 1.0 | Fraction of basis states in the ground-state support |
| `ham_sparsity` | 0.0, 0.25, 0.5, 0.75, 1.0 | Fraction of possible off-diagonal pairs filled in H |
| `overlap` | 0.01, 0.1, 0.3, 0.5, 0.8 | Target \|⟨ψ\|init⟩\|² overlap |
| `keep_states` | 1%, 5%, 10%, 50% of dim | States kept per BARK Hamiltonian application |

**Total full-grid jobs** (before deduplication of identical `keep_states` integers): ~3000.
Run `python generate_jobs.py --dry_run` to get the exact count.

## How to run

### Step 1 — generate the parameter file

```bash
cd ClusterStudy
# Full grid:
python generate_jobs.py --preset full

# Or a small grid for testing:
python generate_jobs.py --preset small
```

The script prints the total number of jobs `N` and writes `params/param_grid.txt`.

### Step 2 — adapt the Slurm script

Edit `run_array.slurm` and update:
- `--account` — your cluster account
- `--partition` — your partition
- `source /home/.../activate` — path to the Python virtual environment
- `cd /home/.../ClusterStudy` — absolute path to this directory

### Step 3 — submit

```bash
# Replace N with the number printed by generate_jobs.py
sbatch --array=0-<N-1> run_array.slurm

# Throttle to 50 simultaneous jobs:
sbatch --array=0-<N-1>%50 run_array.slurm
```

### Step 4 — retrieve results

After jobs complete, all figures are in `results/`. Filenames encode the
parameters:
```
nq8_gs0.10_ham0.50_ov0.30_ks0010_seed42.png
 ^    ^       ^       ^     ^       ^
 |    |       |       |     |       seed
 |    |       |       |     keep_states (zero-padded to 4 digits)
 |    |       |       target overlap
 |    |       Hamiltonian sparsity
 |    ground-state sparsity
 n_qubits
```

## Running a single job locally

```bash
cd ClusterStudy
python run_experiment.py \
    --n_qubits 8 \
    --gs_sparsity 0.1 \
    --ham_sparsity 0.5 \
    --overlap 0.3 \
    --keep_states 10 \
    --n_random_paths 20 \
    --seed 42 \
    --output_dir results
```

## Runtime estimates

| n_qubits | dim | Typical time (100 random paths) |
|----------|-----|---------------------------------|
| 6 | 64 | ~10 s |
| 7 | 128 | ~30 s |
| 8 | 256 | ~2 min |
| 9 | 512 | ~10 min |
| 10 | 1024 | ~60 min |

The bottleneck is `get_all_paths`: each random path requires `dim` eigsh calls
on submatrices up to `dim × dim`.
